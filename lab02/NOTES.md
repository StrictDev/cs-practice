Git - Система контроля версий
GitHub - Облачный сервис хранения программных проектов/кода  

Команды:
git status - Позволяет узнать текущее состояние репозитория, информацию о рабочей ветке.
git diff - Позволяет узнать ещё не добавленные к комиту изменения.
git diff --staged - Позволяет узнать уже добавленные изменения коммита.

Ветки:
Ветки - это разные (параллельные) 'пути' разработки, которые отрастают от основной ветки или от дургих веток,
и имеют собственные коммиты.
При слиянии веток, код и файлы разных веток объединяются в одну, если нет конфликта слияний.
